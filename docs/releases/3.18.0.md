# Version 3.18.0 — Operon 4.4 and semantic search parity

3.18 makes the refusals an agent receives readable and keeps Operon task revisions stable across updates. It also brings semantic search in line with Smart Connections re-indexing.

- **Operon 4.4.0** (`compatible-provisional`): a stale `expectedRevision` returns `revision_conflict` with `currentRevision`, a native refusal `operon_rejected`, an unconfirmed elevated apply `consent_required` and a declined plan `consent_denied`, instead of a generic Bridge error. The task revision now hashes the task only, so an Operon or Bridge upgrade or an edit to a sibling task no longer makes every revision stale (revisions read before this release are stale once: re-read, then plan again).
- **Simpler task calls:** `operon_transition_task` accepts `intent` (`complete`, `cancel`, `reopen`) and resolves the matching status of the task's own pipeline; `operon_query_tasks` accepts `fieldIncludes` for list membership, for example `{ assignees: "Claude" }`. `operon_status` reports `firstUseCapabilities` and `operon_get_diagnostics` reports `bridgeSession`.
- **Faster Operon Bridge 0.9.7:** a refresh reuses the task snapshot while Operon's context revision is unchanged, and keeps established sessions usable during the refresh, so a request right after a write no longer fails as `mutation_unavailable`.
- **Note moves:** a refused native move now says why, with a `reasonCode` and a fixed hint. Atomic Write Bridge 0.9.1 adds `move_reference_limit` (more than 200 links around the source).
- **Semantic search:** a note re-embedded by Smart Connections without a new import stays searchable; the derived cache stores exact vectors in about half the space and rebuilds once after the upgrade; semantic search is no longer reported unavailable right after a restart: while the cache is still loading it is `degraded` with `semantic_index_loading`, then `ready`; a stuck probe reports `semantic_probe_timed_out`. See [semantic vector cache encoding](../semantic-vector-cache-encoding.md).
- **Security:** `follow-redirects` and `@hono/node-server` updated.

Install MCP 3.18.0 with the Bridge bundle of the same release (Atomic Write Bridge 0.9.1, Operon Bridge 0.9.7, Bases Bridge 1.2.2), after draining pending operations. No setting or grant changes. The first semantic query after the upgrade rebuilds the derived cache. See the [changelog](../../CHANGELOG.md#3180---2026-11-03).
