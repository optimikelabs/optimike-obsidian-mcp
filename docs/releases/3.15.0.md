# Version 3.15.0 — audit follow-ups

This release adds governed note deletion, WAL maintenance, journal hygiene and corrected inline tag extraction. It also adds opt-in ChatGPT tool-result compatibility and operational diagnostics. See the [changelog](../../CHANGELOG.md#3150---2026-10-27) and [audit follow-ups](../audit-followups-20261027.md).

Install MCP 3.15.0 and Atomic Write Bridge 0.8.5 together; drain pending operations and preparation fences, and verify artifact hashes before switching or rolling back the pair. The Bridge setting requiring a fence for every write remains off by default.

Governed deletion is disabled by default in the Bridge, requires `MCP_WRITE_MODE=full`, and refuses a Bridge without the deletion capability. It uses Obsidian trash, refuses permanent deletion, and refuses incoming links unless explicitly acknowledged. See [governed note deletion](../governed-note-delete.md).

Administrative closure does not establish whether an uncertain historical effect occurred. The remote ChatGPT path and other environments require their own qualification.
