# Version 3.17.0 — Bases et Canvas gouvernés au complet

La 3.16 permettait à un agent de créer une Base ou un Canvas en mode gouverné. La 3.17 lui permet de les modifier entièrement, toujours en mode gouverné.

- **Bases :** `bases_config_patch_plan` → `_apply` → `_status` (`_recover` après une issue incertaine) modifie une Base existante en entier : filtres globaux, formules, réglages des propriétés (`displayName`…), résumés et vues (ajouter, supprimer, déplacer, renommer, type, filtres, ordre, tri, regroupement, résumés, limite, toute clé de vue ou de plugin). Les commentaires et les valeurs non touchées sont conservés ; le résultat doit être une Base valide. Voir la [configuration gouvernée d’une Base](../governed-base-config.fr.md).
- **Canvas :** le patch Canvas gouverné couvre désormais toutes les options JSON Canvas : nœuds fichier (avec une section `#`), nœuds lien, groupes avec titre et fond, couleurs et champs des nœuds, étiquettes, couleurs, côtés et flèches des arêtes.

Aucun changement de Bridge : installer le MCP 3.17.0 avec le bundle des Bridges 3.16.0 (Atomic Write Bridge 0.9.0). Les modifications de Base utilisent le réglage existant **Allow atomic Base CAS** du Bases Bridge ; celles des Canvas, **Allow atomic Canvas writes** de l’Atomic Write Bridge. L’ancienne réécriture complète `bases_upsert_config` reste une voie de compatibilité, désactivée par défaut. Voir le [changelog](../../CHANGELOG.md#3170---2026-10-28).
