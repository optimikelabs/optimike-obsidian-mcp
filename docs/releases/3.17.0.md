# Version 3.17.0 — complete governed Bases and Canvas

3.16 let an agent create a Base or a Canvas in governed mode. 3.17 lets it edit them completely, still in governed mode.

- **Bases:** `bases_config_patch_plan` → `_apply` → `_status` (`_recover` after an uncertain outcome) edits a whole existing Base: global filters, formulas, property settings (`displayName`…), summaries and views (add, delete, move, rename, type, filters, order, sort, grouping, summaries, limit, any view or plugin key). Comments and untouched values are kept; documented view keys are checked; a plugin view type such as `kanban` needs `pluginViewType: true`; the result must be a valid Base. See [governed Base configuration](../governed-base-config.md).
- **Canvas:** the governed Canvas patch now covers every JSON Canvas option: file nodes (with a `#` section), link nodes, groups with label and background, node colors and fields, edge labels, colors, sides and arrows.

No Bridge change: install MCP 3.17.0 with the 3.16.0 Bridge bundle (Atomic Write Bridge 0.9.0). Base edits use the existing **Allow atomic Base CAS** setting of the Bases Bridge; Canvas edits use **Allow atomic Canvas writes** of the Atomic Write Bridge. The old whole-file `bases_upsert_config` stays a compatibility path, off by default. See the [changelog](../../CHANGELOG.md#3170---2026-10-28).
