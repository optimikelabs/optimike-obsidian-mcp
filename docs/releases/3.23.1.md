# Version 3.23.1 — Antigravity loads the catalogue, Codex finds the due-date tool

3.23.1 fixes a schema that stopped Antigravity from loading any tool of this server, and rewords two Operon descriptions for clients that choose tools by reading names and descriptions, such as Codex.

- **Antigravity-compatible cursor (PR #197):** Antigravity 1.5.12 could not compile the `{1,2048}` repetition in the `cursor` pattern of `obsidian_list_pending_operations`, so it refused the whole toolbox and no request reached the model. The published pattern is now `^[A-Za-z0-9_-]+$`; the server still refuses a cursor longer than 2048 characters or outside that alphabet. Only this pattern changes in the 104-tool catalogue. Antigravity 1.5.12 now lists the catalogue and picks the right tool in 85 of 104 replayed requests; Claude Code and Codex get the same catalogue as before.
- **Due date and recurrence descriptions (PR #198):** `operon_update_task` now opens with changing the due date (`dateDue`) or other fields of an existing task, and `operon_update_recurrence` with the rule of a repeating task. Codex never reads `_meta["anthropic/searchHint"]`, so it did not benefit from the 3.23.0 hints: on "move the due date" requests, Codex CLI and Codex inside T3 went from 0 of 4 to 4 of 4. Over 104 replayed requests: Codex CLI 100 → 104, Codex in T3 99 → 103, Claude Code 104 → 104, Mistral Vibe 87 → 89, Antigravity 85 → 86. Only these two descriptions change; schemas, hints, instructions, profiles and enforcement are unchanged.
- **Discovery eval (PR #196):** an exact tool name in a corpus case is resolved before discovery aliases, so a case can no longer be scored against the wrong tool.

These are single-run comparisons on a replay server that refuses every tool call. An A/A run with an identical catalogue on both sides flipped 8 of 28 pairs, so a gap of one answer per case is noise; the two cases that had worsened were replayed 8 times on each side before merging (Codex in T3: 8/8 against 8/8; Mistral Vibe Canvas creation: 5/8 against 6/8).

**Bridges:** no Bridge change. Atomic Write Bridge 0.10.0, Operon Bridge 0.9.9 and Bases Bridge 1.3.0 ship unchanged in the bundle of this release: upgrading from 3.23.0 or 3.22.0 needs no Bridge reinstall. See the [changelog](../../CHANGELOG.md#3231---2026-11-26).
