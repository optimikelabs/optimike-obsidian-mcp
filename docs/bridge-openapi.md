# Optional Bridge OpenAPI inventory

The three Bridges use public Local REST extension types. The type-only development dependency is pinned to npm obsidian-local-rest-api 5.3.0 (published package observed on 28 September); this does not certify the installed host as 5.3.1. No host plugin bundle is imported at runtime.

A registration observer records successfully registered authenticated paths and methods only. Native handles, receivers, handlers, chaining and unregister ownership remain unchanged. No handler is dispatched and no MCP tool is added. The existing lifecycle supervisor still owns late startup, reload and cleanup.

Extension API v3 plus addOpenApiDescription permits one contribution after mount. Old hosts retain their routes. A publication failure or collision does not unmount them. The console diagnostic is only published, unsupported or failed; no private exception/payload is logged.

## Coverage boundary

Paths carry x-optimike-express-pattern; operations carry x-optimike-schema-coverage: route-and-method-only. The original pattern identifies greedy Bases parameters. This is not a complete request/response JSON Schema, a live permission probe or an authorization grant. Consult the versioned Optimike mutation contracts and capability doctor before acting. No private examples, credentials or physical paths are published.

Complete payload schemas are not invented from Express handlers. Future schema expansion must share actual validators or prove parity independently.

## Proofs

npm run test:bridge-openapi covers old hosts, absent methods, collisions, invalid patterns, publication idempotence, receiver identity, chaining, unregister and remount. The actual three Bridge entrypoints are bundled and mounted against controlled providers. Registered path/method sets match the inventory and stay identical on old/current/colliding hosts. These are repository fixtures, not Desktop qualification. Existing Bridge suites and packaging remain required.

Desktop gate: use an attested disposable vault only. Compare routes and merged OpenAPI, disable/re-enable Local REST and each Bridge, verify recovery, no stale contribution and unchanged write grants. Do not run this gate against a personal vault implicitly.
